# Topic photos for thumbnails

Put a photo of the quiz's subject here (a person, a place, an animal), and name it in the CSV:

```
Thumbnail image,ms_dhoni.jpg
```

You can also add one to an existing video from its page in the studio (Thumbnail → Topic photo).
The thumbnail designer puts it in a big frame next to the title. A **PNG with a transparent
background** (a cut-out) is placed without a frame, which looks even better.

## Licence rules: only photos you are allowed to use

A copyright claim or strike can block a video, so never take a photo from Google Images, news
sites or Instagram. Use:

- **Wikimedia Commons** (commons.wikimedia.org): photos marked CC0, Public domain, CC BY or
  CC BY-SA. Add the credit line to `CREDITS.json` and it goes into the YouTube description by itself.
- Photos you took yourself, or ones you have bought a licence for.

Don't use AI-generated pictures of real people: YouTube treats realistic fakes of real people as
altered content.

`CREDITS.json` holds `"file name": "credit text"` for every photo that needs credit.
