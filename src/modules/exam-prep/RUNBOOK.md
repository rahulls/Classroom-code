# Tutor runbook (one page)

Open **http://localhost:4310/exam-prep**. The **Today** screen lists this week's tasks with due times.
Press **Run the weekly jobs now** if the laptop was off.

## Papers you make yourself

**Papers → New paper → "Upload my own file (PDF or CSV)"**: give the total marks and attach the file,
then **Publish**. On the paper page, **Files** also holds the answer key and solutions. Uploading again
keeps the older version. **Draft group posts** puts the tagged post and the key post in Messages, each
with a **⬇ file** button to attach. AI marking, chapter analytics and automatic reports need a paper
built question by question; uploaded papers keep the tracker and filed sheets.

## The week

| When (IST) | Do |
|---|---|
| **Mon 9:00** | **Papers:** publish each paper attached in the Calendar. **Messages:** post the tagged group post (`[Class 10 \| CBSE \| Maths \| Paper 1]`) with the paper PDF; pin the week's calendar. |
| **Wed 18:00** | Post the Wednesday reminder. |
| **Thu 20:00 (deadline)** | Paper → **Tracker**: send the drafted private reminders (one per student per paper). File sheets as they arrive (**File a sheet**), and import the Form's MCQ answers. |
| **Fri** | Post the answer key and solutions (paper PDFs). Paper → **Marking** → **Propose marks with AI**. |
| **Sat** | **Marking:** clear the needs-review list (A accept, E edit, R reject, 1-4 error type). Pick the spot-check sheets and enter your totals; correct any sheet that's off. Then **Finish marking**. |
| **Sun 17:00** | Paper → **Generate reports**: check a few, then **Approve and deliver**. Emails go out by themselves. **Reports:** send each queued WhatsApp report (PDF + message) and press *Sent*. **Draft class note** → post it. **Ranks:** tell consenting students personally, then *Mark told*. |

## Sunday 30-minute review (Metrics → checklist)

1. All marks reviewed; spot-check recorded and the mismatch rate looks low.
2. Reports approved; email failures retried; WhatsApp queue empty.
3. Class notes posted (weakest chapters only, never names or scores).
4. Ranks told; follow-ups checked (students who stopped after a bottom-third rank).
5. Replies logged on each student's page (for the reply-rate metric); offers reviewed in Plans.
6. Opt-outs and complaints handled.
7. Next week's papers attached and published.
8. Hours logged.

## Opt-outs, deletions, corrections

- **STOP received:** open the student → *STOP: opt out* (parent) or *Opt the student out*. They leave every
  queue at once, and a confirmation is drafted in Messages: send it.
- **Delete request:** open the student → *Privacy* → type DELETE. Files, marks, reports and ranks are
  removed, and a confirmation message is drafted. The request is listed under Privacy.
- **Data copy request:** open the student → *Export this student's data (ZIP)*.
- **Wrong mark:** Paper → Marking → pick the sheet → *Enter or correct a mark*, and add a correction note.
  The next report mentions it. For a report already sent: Reports → *Force resend* (it is regenerated).

## Never

- Post a score, rank or report in the group.
- Send anything to a number that isn't verified.
- Share a file link: links expire after 5 minutes and only work while you're signed in.
